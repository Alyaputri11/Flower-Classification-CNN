# Flower Classification Using CNN

## Project Overview
This project implements a **Convolutional Neural Network (CNN)** to classify flower images into five categories using image classification.

The model learns visual features from flower images and predicts which category an input image belongs to.

## Objectives
- Understand the basic concept of Convolutional Neural Networks.
- Build a CNN model for image classification.
- Train and validate the model using a flower image dataset.
- Evaluate model performance using accuracy.
- Visualize sample predictions.

## Dataset
This project uses the TensorFlow flower photos dataset.

The dataset contains five categories:
1. Daisy
2. Dandelion
3. Roses
4. Sunflowers
5. Tulips

Dataset archive: https://storage.googleapis.com/download.tensorflow.org/example_images/flower_photos.tgz

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Google Colab

## CNN Architecture
The model includes:
- Data augmentation
- Rescaling
- Convolutional layers (Conv2D)
- Max pooling layers (MaxPooling2D)
- Flatten layer
- Dense layer
- Dropout
- Softmax output layer

## How to Run
1. Open [Google Colab](https://colab.research.google.com/).
2. Upload `flower_classification_cnn.ipynb`.
3. Select **Runtime → Run all**.
4. The notebook downloads the dataset, trains the CNN, evaluates validation accuracy, and displays prediction examples.

## Expected Output
The notebook displays:
- Sample flower images and their labels.
- CNN model architecture.
- Training and validation accuracy.
- Validation accuracy score.
- Predicted flower categories compared with their actual labels.

The actual accuracy is generated by running the notebook and may vary.
